# Husna Aafiyah Birthday RSVP

A small digital birthday invitation + RSVP website based on the supplied invitation poster.

## Files

- `index.html` — website structure
- `style.css` — pink bow/flower visual theme
- `script.js` — opening animation, guest counter and temporary RSVP confirmation
- `poster.jpg` — supplied invitation poster

## Next step

The RSVP form is currently front-end only. Connect it to Google Sheets using Google Apps Script so every submission is saved automatically.

After that, publish this folder using GitHub Pages and create a QR code for the poster.
